# MeghaAI React UI 🚀

A modern, responsive React web application built using **Vite** and **React Router**, designed for scalable UI architecture and smooth user experience.

## 🌐 Live Website

👉 [https://shrinkhla1819.github.io/MeghaAI-React-UI/]

---

## ⚙️ Tech Stack

* ⚛️ React
* ⚡ Vite
* 🔀 React Router DOM
* 🎨 Custom CSS & Animations
* 🚀 GitHub Pages Deployment
* 🤖 GitHub Actions (Auto Deployment)

## 🛠 Installation

Clone the repository:

```
git clone https://github.com/shrinkhla1819/MeghaAI-React-UI.git
cd MeghaAI-React-UI
npm install
npm run dev
```

---

## 📦 Production Build

```
npm run build
```

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

Every push to the `main` branch updates the live website.
